\subsection{Empirical Verification of Scaling Exponent (Proposition~3)}
\label{sec:prop3_verification}

Proposition~3 assumes linear scaling $g(L) = \alpha L$ to justify that $Z^\star = Z/L$ blocks the backdoor path $Z \leftarrow L \rightarrow Y$. We verify this assumption empirically via OLS regression of $\log P_1$ on $\log N$ across all benchmarks. An exponent $\hat{\alpha} \approx 1$ justifies the linear normalization; if $\hat{\alpha} \neq 1$, the correct normalization is $Z^\star = Z / N^{\hat{\alpha}}$.
