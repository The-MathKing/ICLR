\subsection{Power Analysis and Minimum Detectable Effect}
\label{sec:power}

A null result is only informative if the study had sufficient power to detect a practically meaningful effect. We compute the Minimum Detectable Effect (MDE) in $\Delta\text{AUC}$ for each benchmark under the cluster-bootstrap sampling distribution. Using the empirical bootstrap standard error $\hat{\sigma}$ as the estimator of the true sampling uncertainty, the MDE at 80\% power and $\alpha=0.05$ (two-sided) is:
\begin{equation}
    \mathrm{MDE} = (z_{0.025} + z_{0.20}) \cdot \hat{\sigma} = 2.802 \cdot \hat{\sigma}.
\end{equation}
